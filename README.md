# Telltale

An AI-writing-tell detector landing page — built to explore and visualize the linguistic
patterns (perplexity, burstiness, syntactic rhythm, semantic flatness) that distinguish
AI-generated text from human writing.

Built with HTML, CSS, and JavaScript. Deployed via Netlify.

## Live site
https://telltaledetector.netlify.app 

## Status
In progress — currently wiring up the Anthropic API to power live detection.
